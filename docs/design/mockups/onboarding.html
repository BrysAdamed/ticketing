Onboarding

Ticketing mockup · spec §14 · TKT-75

The onboarding surfaces in one place: the welcome dialog, the getting-started checklist on My work, a tour step with its spotlight, inline hints, the Help menu, the paused "Your first project" walkthrough and the learn actions on empty states. Only the welcome dialog and What's new open by themselves; everything else starts from the Help menu, the palette, the welcome dialog or an empty state.
