# Payment flow
> [!NOTE]
> Target flow for Checkout v2. Migration progress is tracked in PAY-1.
## Overview
Checkout creates a **PaymentIntent** on the server and the browser only confirms it. Order state follows Stripe webhooks, never the browser. See [[Webhooks & outbox]].
## Sequence
```mermaid
sequenceDiagram
participant B as Browser
participant API as Checkout API
participant S as Stripe
participant W as Webhook worker
B->>API: POST /checkout/pay
API->>S: create PaymentIntent
S-->>API: client_secret
API-->>B: client_secret
B->>S: confirm payment + 3-D Secure
S->>W: payment_intent.succeeded
Note over W: store event → outbox
W->>API: mark order Paid
```
